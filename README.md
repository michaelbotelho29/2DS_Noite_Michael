3. Nome do Sistema/App:
Social M Sync

4. Descrição Geral:
O Sistema visa agilizar as postagens em Redes Sociais. O sistema
iria centralizar várias redes sociais dentro dele e fará isso para que
o usuário possa postar apenas pelo Social M Sync e o app postaria
nas redes para ele.
5. Requisitos Funcionais (O que o sistema FAZ):
o Liste 5 funcionalidades principais do sistema (Exemplo: 1. O
cliente pode visualizar os horários disponíveis; 2. O barbeiro
pode cancelar um agendamento...).
Sincronizar suas Redes Sociais.
Postar simultaneamente em todas as Redes Sociais.
Armazena suas postagens.
Centraliza as notificações de todas as Redes Sociais.
o Permite o carregamento de imagens e vídeos

6. Requisitos Não-Funcionais do Projeto (Como o
sistema SE COMPORTA):
Manutenibilidade, Chat Privado, Botão De Suporte.
o Segurança: Quais dados confidenciais dos usuários o sistema
precisará proteger contra vazamentos?
Login/CNPJ, Senha, Dados Bancários, Login das Redes Sociais
e Telefone.
o Pico de Uso: Em quais dias da semana ou horários do dia
vocês preveem que o sistema de vocês receberá o maior
volume de acessos ao mesmo tempo?
Seria razoável durante o horário de pico e maior número de
acessos aos fins de semana.
